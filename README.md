# Мой первый персональный сайт

Современный адаптивный сайт на русском языке: главный экран, «Обо мне», карточки проектов и контакты. Тёмная тема, фиолетово-синие градиенты, анимированная сфера и плавное появление разделов. Только HTML, CSS и JavaScript — установка пакетов и сборка не нужны.

## Как посмотреть сайт

**Самый простой способ на своём компьютере:** скачайте репозиторий через GitHub → **Code → Download ZIP**, распакуйте архив и дважды нажмите `index.html`. Он откроется в браузере.

**В облачной среде или для локальной разработки:** откройте терминал в папке проекта и выполните:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

На своём компьютере откройте `http://localhost:8000`. В облачной среде используйте предпросмотр порта 8000, если ваш интерфейс его поддерживает. Адрес localhost на вашем компьютере не открывает сервер облачной среды. Чтобы остановить сервер в терминале, нажмите **Ctrl+C**.

Шрифт Manrope загружается из Google Fonts. Без интернета сайт работает с системным шрифтом. Сайт не отправляет формы, не собирает данные и не требует ключей доступа.

## Что находится в проекте

- `index.html` — текст, разделы, ссылки и карточки проектов.
- `styles.css` — цвета, адаптивный дизайн и анимации.
- `script.js` — мобильное меню, анимация появления разделов и год в подвале.

## Как сделать сайт своим

Откройте `index.html` в редакторе. Замените приветствие и текст «Обо мне», добавьте реальные проекты. В контактах уже стоит ссылка на профиль `https://github.com/Elys2017`. Её можно заменить своей ссылкой или адресом `mailto:you@example.com`. Второй проект явно отмечен как идея в планах — это не готовое приложение. Сохраните файл и обновите страницу браузера.

Все основные разделы доступны без JavaScript. Анимации учитывают системную настройку уменьшения движения; меню поддерживает клавиатуру и закрывается клавишей Escape.

## Как сохранить изменения на GitHub

В терминале из папки проекта:

```bash
git status
git add index.html styles.css script.js README.md
git commit -m "Create personal website"
git push -u origin HEAD
```

Команда `git push` сохраняет код на GitHub и требует доступа к репозиторию. Если текущая ветка называется `work`, на GitHub появится ветка `work`: откройте **Compare & pull request**, создайте запрос и объедините его с `main` кнопкой **Merge pull request**. Если изменения уже сохраняет ваш интерфейс Codex, воспользуйтесь его командой создания коммита или pull request.

Сохранение кода и публикация сайта — разные действия. В этом проекте не настроена автоматическая публикация. GitHub Pages и другие сервисы размещения включайте только тогда, когда решите сделать сайт общедоступным.
